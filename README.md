# 🌌 Minimalist 3D Solar Portfolio

A high-performance personal portfolio website built with a modern, minimalist dark aesthetic, featuring an interactive 3D solar environment.

🔗 **Live Demo:** https://neha-patil-portfolio.vercel.app

---

## 🚀 Features

- **Interactive 3D Visuals:** Immersive space atmosphere with custom shaders and God Rays built using Three.js.
- **Responsive Architecture:** Fully optimized dynamic layouts tracking flawlessly across desktop and mobile screens via Tailwind CSS.
- **Dual Mode Assets:** Fluid interface interactivity featuring integrated custom digital CV tools and dedicated resume views.
- **Clean Aesthetics:** Minimalist typography and sleek UI accents tailored for modern digital branding.

---

## 🛠️ Tech Stack

- **Frontend Core:** HTML5, CSS3, JavaScript (ES6+)
- **3D Graphics & Rendering:** Three.js / Vite
- **Styling Pipeline:** Tailwind CSS, PostCSS
- **Deployment Platform:** Vercel
